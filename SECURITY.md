# Security

This gateway is pre-release, has not been validated against Stripe, and has no
supported release series. The sandbox checks in [verification](docs/verification.md)
remain pending.

Report vulnerabilities privately: on this repository, open
**Security → Report a vulnerability**. Do not use public issues, discussions or
pull requests for security problems.

Never post Stripe keys, webhook signing secrets, client secrets, customer data,
payment records or raw provider responses publicly.

Include the affected revision, the impact and a minimal synthetic reproduction.
Keep real account and customer evidence private.
