# Security

This gateway is pre-release, has not been validated against Stripe, and has no
supported release series. The sandbox checks in [verification](docs/verification.md)
remain pending.

Keep Stripe keys, webhook signing secrets, client secrets, customer data, payment
records and raw provider responses out of public issues and pull requests.
Use GitHub's private vulnerability reporting for this repository when available.
If unavailable, contact the maintainer through their GitHub profile to arrange a
private channel before sharing sensitive details.

Identify the affected revision, impact and a minimal synthetic reproduction.
Keep real account and customer evidence private.
